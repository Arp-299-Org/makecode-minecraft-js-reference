# API reference

Generated from MakeCode for Minecraft **v2.1.27** (pxt 12.1.17), the editor used by Minecraft Education's Code Builder.

## Minecraft

- [player](player.md) (23) - Give commands, communicate, and respond to events that happen in the game
- [agent](agent.md) (27) - Your assistant in Minecraft to help you get things done.
- [blocks](blocks.md) (22) - Everything for adding, inspecting, and changing blocks in the world.
- [mobs](mobs.md) (32) - Creatures that live in the Minecraft world.
- [gameplay](gameplay.md) (14) - Commands to control the game mode, weather, time, and change the rules.
- [positions](positions.md) (10) - World and relative position operators
- [builder](builder.md) (21) - A 3D builder interface
- [shapes](shapes.md) (3) - Fill lines, spheres and other geometric shapes
- [events](events.md) (29) - Run code when things happen in the world: blocks broken or placed, items crafted, mobs killed, players moving, and more.

## Extensions

Not part of a new project. Add **File Read & Write** from **Extensions** in Code Builder first.

- [file](file.md) (2) - Read and write text or CSV files chosen with a file picker.

## Alternate names (not available by default)

These come from the `nether` library bundled with the editor. It is not loaded in Minecraft Education projects, so `user.` and `exploration.` give an error. They mirror the player/gameplay APIs under different names.

- [user](user.md) (16) - Give commands, communicate, and respond to events that happen in the exploration
- [exploration](exploration.md) (12) - Commands to control the exploration mode, weather, time, and change the rules.
