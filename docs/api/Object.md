Object helpers.

| Member | Description |
|---|---|
| [`keys`](#keys) | Return the field names in an object. |

## keys

Return the field names in an object.

```typescript
Object.keys(obj: any): string[]
```

| Parameter | Type | Description |
|---|---|---|
| `obj` | `any` |  |

**Returns:** `string[]`

**Block:** none. This is available in JavaScript only.

```typescript
let result = Object.keys("hello")
```
